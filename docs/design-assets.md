# DataMind visual refresh

The existing navy/teal design is extended with warm-white surfaces, editorial typography, accessible form states, responsive workspace navigation, and clearly labeled sample data.

The Product Design workflow guided visual consistency and interaction checks. The built-in image generation tool produced the decorative 3D asset at `frontend/public/images/data-sculpture.png`; it is a transparent image, not an interactive 3D model. CSS adds a gentle floating motion with a reduced-motion alternative.

## Asset generation prompt

Use case: stylized-concept. Asset type: polished 3D illustration for an existing DataMind AI analytics website, a right-side hero visual and an authentication sidebar. Create a premium editorial studio 3D render of three ascending translucent teal glass chart columns with rounded bevels, a large elegant satin ceramic teal torus looping behind the columns, and a small hovering brushed-silver sphere. The objects form one coherent sculptural data-intelligence still life, on a round milky-white low pedestal. Orthographic camera looking slightly downward, composition centered with generous breathing room, soft realistic contact shadows, ray-traced refractions and beautiful caustics. Palette: deep petrol teal #0D9488, icy pale mint, warm white, subtle silver; no purple. Transparent background with isolated objects and subtle shadow. No text, no logos, no UI, no numbers, no grids. Square 1024 pixel composition. High-end art direction, tactile glass and porcelain, dimensional but restrained.

## Sample workspace

The sample preview is entirely local. It uses six explicit monthly records and computes totals and rankings from those records. It does not represent uploaded data or a live AI response. Upload and live analysis availability is explained in the UI.
